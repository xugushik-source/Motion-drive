# MOTION DRIVE

Локальная рабочая основа четырёхъязычной платформы автошколы для Ахалкалаки и Ниноцминды. **Не опубликована. Платные AI-вызовы отключены. Обучение и наполнение экзаменационной/AI-базы отложены до материалов владельца.**

## Запуск

Нужен Node.js 24+ (используется встроенный `node:sqlite`).

```bash
cd /workspace/motion-drive
npm ci
npm run dev
```

Открыть http://localhost:3000/ru (также `/ka`, `/hy`, `/en`).

Для производственного локального просмотра:

```bash
npm run build
npm start
```

Данные создаются в `data/motion-drive.sqlite`, загруженные файлы — в `data/uploads`. Не теряйте их при переносе. Код сам по себе не содержит персональных данных или секретов; `data/`, `.env*` исключены из Git.

## Администратор

Нет общего или опубликованного пароля. Пользователь регистрируется как ученик. Для первого администратора остановите сервер и выполните в терминале (секрет не вводить в чат):

```bash
read -r -p 'Admin email: ' ADMIN_EMAIL
read -r -s -p 'New password (12+ characters): ' ADMIN_PASSWORD
export ADMIN_EMAIL ADMIN_PASSWORD
npm run setup:admin
unset ADMIN_EMAIL ADMIN_PASSWORD
```

После запуска войдите через `/ru/account`, затем откройте `/ru/admin`. Если такой email уже зарегистрирован, команда не перезаписывает его пароль или роль; используйте отдельный административный email. Для реального запуска нужны MFA, подтверждение email и восстановление пароля — пока они не подключены.

Черновики филиалов из проверенных публичных источников можно добавить после первого запуска:

```bash
node scripts/seed-drafts.mjs
```

Инструктор сначала регистрируется; администратор назначает роль во вкладке «Ученики» и связывает профиль с ID пользователя. Кабинет инструктора — `/ru/instructor`.

## Что работает

- Публичные маршруты на четырёх языках, переключение языка, адаптивное меню, анимации с reduced motion, локальные шрифты.
- Курсы/тарифы/филиалы/галерея/FAQ/отзывы из CMS, редактор переводов. Отсутствующие данные явно обозначены, фиктивных цен/инструкторов/отзывов нет.
- Регистрация, вход, серверные сессии и роли. Личный кабинет с реальными данными, без нарисованного прогресса.
- Сохранение заявки; согласование времени без опубликованного расписания; создание слотов; защита от двойного бронирования; перенос, подтверждение и отмена; назначенные инструктору ученики и отметки проведённых занятий.
- Учебный движок: импорт проверенных вопросов, языковые варианты, случайная выборка, таймер, оценка, разбор и история. База пока пустая по указанию владельца.
- Чат: утверждённый FAQ, fallback без ключа, сохранение неизвестных обращений, передача администратору. Серверный адаптер Responses API готов, платная ветка не тестировалась и отключена.
- Черновой импорт текстовых обращений: маскирование контактов, группировка одинаковых вопросов, частоты и ручное утверждение. Смысловая кластеризация/AI-черновики/обучение отложены.
- Медиа: локальная загрузка, фильтр фото/видео, полноэкранный просмотр, плееры, фоновые видео с экономной загрузкой.

## Что ждёт подключения / согласования

PostgreSQL и объектное хранилище для публичной среды; OpenAI API после отдельного разрешения и лимитов; Instagram/Messenger после проверки Meta; email/SMS, восстановление пароля и верификация email; аналитика; утверждённые данные школы, права на фото/видео, проверка переводов носителями и юридические тексты. Публичный деплой не выполнялся. Уведомления сейчас только в кабинете.

Эта версия — основа для проверки владельцем, **не завершённая публичная эксплуатационная система**. Локальный SQLite выбран для запуска без внешних аккаунтов; переход на PostgreSQL требует отдельной реализации, это не уже подключённая Supabase.

```

```
