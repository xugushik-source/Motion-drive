## Где проект

`/workspace/motion-drive`. Собственный локальный Git-репозиторий, ветка `motion-drive-foundation`; удалённый репозиторий ещё не подключён. Node 24+, npm. Локальный просмотр: npm ci, npm run dev → http://localhost:3000/ru.

Четыре языка, CMS, регистрация/роли, запись/слоты/перенос/отмена, пустой учебный движок, FAQ-чат и серверный AI-адаптер реализованы. Реальное состояние проверок см. docs/VERIFICATION.md. Не считать платный OpenAI, Meta, почту/SMS, PostgreSQL, аналитику подключёнными. Не заполнять фиктивными вопросами/отзывами/ценами.

## Что сохранить при переносе

1. Исходники вместе с lockfile и документацией; `motion-drive-source.tar.gz` — переносимая копия без зависимостей, персональных данных и секретов.
2. Отдельно актуальные `data/motion-drive.sqlite` и `data/uploads`, если уже появились реальные записи. SQLite копировать при остановленном сервере или через backup API, не просто копировать открытый WAL-файл.
3. Серверные секреты передавать только через защищённые настройки новой среды. Не класть их в чат или архив исходников.
