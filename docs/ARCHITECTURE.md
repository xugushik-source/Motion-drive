# Архитектура и ограничения

## Локальная реализация

Next.js 16 / React / TypeScript, next-intl, Motion, собственный CSS. Tailwind и GSAP не добавлены: текущие эффекты не требуют дополнительных зависимостей.

SQLite через встроенный `node:sqlite` выбран для проверяемого локального запуска без аккаунтов и покупки инфраструктуры. Данные переживают перезапуск. Это явное отклонение от предпочтения PostgreSQL/Supabase. Для публичной многосерверной среды нужен отдельный перенос слоя `src/lib/db.ts` на PostgreSQL, транзакционные блокировки/ограничения расписания и объектное хранилище. SQLite нельзя размещать на эфемерном или нескольких независимых serverless-дисках.

- `users`, `sessions`: scrypt-пароли, случайные HttpOnly сессии, SameSite=Lax, secure при HTTPS APP_URL. Ученик создаётся только в роли student. Администратор создаётся локальной командой, общего пароля нет.
- `bookings`, `slots`: реальные заявки и расписание; частичный UNIQUE-индекс запрещает занять один слот дважды. Отмена освобождает слот. Согласование без расписания остаётся pending; администратор не может подтвердить заявку без времени. Перенос на другой слот вновь требует согласования.
- `records`: управляемые курсы, филиалы, медиа, отзывы, FAQ, знания, переводы, материалы, настройки; `audit` хранит изменения. Публикация записи внутри локальной CMS не является публичным деплоем сайта.
- `lessons`: отметка инструктора, навыки и рекомендации. Обрабатываются только назначенные ему заявки. Ученик видит только собственные данные. Процент готовности без базы/учебного плана не рисуется.
- `attempts`, `results`: случайные проверенные вопросы выбранного языка, серверный таймер, правильные ответы не выдаются до завершения, разбор и результаты. Временные параметры по умолчанию 20 минут / до 20 вопросов — настройки учебного тренажёра, не правила официального экзамена. Вопросы школа добавит позже.
- `uploads`: локальные JPEG/PNG/WebP/MP4/WebM до 25 МБ; MIME определяется по заголовку; SVG/HTML запрещены; неопубликованные файлы доступны только админу. Для больших видео нужны объектное хранилище, перекодирование и CDN. Внешние видео ограничены YouTube privacy-enhanced embed и Vimeo.
- Hero video: локальный MP4/WebM, poster; не загружается при reduced motion, saveData и медленном соединении. У видео в CMS задать `placement: "hero"` в расширенных полях. Медиа не загружаются с чужих школьных аккаунтов.
- `messages`: ответы FAQ, неизвестные вопросы/передача школе, история обращений зарегистрированных пользователей. Гость должен оставить контакт в заявке, иначе школа не может связаться с ним вне чата.

## AI

Сначала точное нормализованное совпадение утверждённого FAQ/знания. Если ответа нет — честный fallback и запись обращения. Это не семантический поиск и не дообучение. Точность требует утверждённой базы.

Responses API включается только серверной настройкой `OPENAI_ENABLED=true`, ключом, моделью, проверенными ценами токенов и ненулевыми дневным/месячным бюджетами после отдельного разрешения владельца. Конкретную модель не выбираем по памяти. До разрешения актуальность модели через платный запрос не проверяется. Система резервирует верхнюю оценку расхода перед запросом, затем уточняет по usage. Неизвестный исход сетевого запроса оставляет резерв. Есть ограничения размера и частоты и `store:false`.

Это локальная защита бюджета, не замена жёстким лимитам организации OpenAI. Для многопроцессной среды нужна распределённая атомарная квота. Платная ветка не вызывалась и требует интеграционной проверки после разрешения.

Импорт CSV/JSON/строк: черновики, маскирование email/телефонов/URL/@аккаунтов, определение алфавита, группировка одинаковых формулировок и частота. Полная деидентификация имён и смысловая кластеризация не реализованы — требуется человек. AI-черновики ответов и обучение отложены по указанию владельца. Ни один импорт автоматически не попадает в опубликованные знания.

## Настройки CMS

Поддерживаемые ключи: `booking_enabled` (`true`/`false`), `site_description`, `exam_minutes` (1–60), `exam_question_count` (1–60). Для применения требуется статус published. Остальные расширенные поля описаны примерами в `docs/CONTENT.md`.

## До публичного запуска

Нужны HTTPS-домен и утверждённый деплой, PostgreSQL/хранилище/резервирование, проверка переводов носителями, реальные материалы, юридические условия и сроки хранения/удаления данных. Email verification, recovery, MFA, транзакционные email/SMS, CAPTCHA и внешние уведомления не подключены. Уведомления сейчас — состояния в кабинете. Ограничитель частоты хранится локально: необходимы доверенный reverse proxy и распределённые квоты при масштабировании.

Instagram Direct/Messenger/WhatsApp/Telegram не подключены. Для Meta нужны отдельная проверка разрешений, аккаунтов, webhooks и актуальных API. Никаких имитаций подключения. Аналитика и Google Business Profile не подключены.

SEO подготовлен: локализованные маршруты, canonical, hreflang, sitemap, OpenGraph и минимальная Schema.org без неподтверждённых адресов/рейтингов. Локальная версия намеренно `noindex`, robots запрещает индексацию. Снять ограничение только при утверждённом запуске.
