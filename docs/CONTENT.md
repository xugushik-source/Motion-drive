# Контент без редактирования кода

Войдите с ролью admin и откройте `/ru/admin`. Все записи по умолчанию черновики. Веб-сайт показывает только опубликованные записи. Для переводов используйте отдельную запись каждого языка.

- Филиалы: город (`akhalkalaki` / `ninotsminda`), адрес, телефон. Часы `hours` можно внести через расширенные поля. Источники контактов сохранены в черновиках seed-drafts.
- Курсы: заголовок, описание, цена GEL (пусто = уточняется), длительность. Текущий выбор заявки сохраняется в категориях theory/practice/individual/group/exam; произвольные новые категории требуют расширения схемы. Публикация карточки не назначает курс ученику автоматически.
- Инструкторы: сначала пользователь регистрируется; администратор меняет его роль во вкладке «Ученики». Затем создаёт профиль и указывает ID аккаунта. `languages`, `vehicle`, `image` — дополнительные подтверждённые поля. Фото можно загрузить через модуль медиа и использовать его URL.
- Расписание: администратор выбирает реальный аккаунт инструктора; инструктор может создавать только собственные слоты. Ввод даты — по времени Грузии UTC+04:00. В карточке заявки можно выбрать свободный слот, сохранить перенос и подтвердить заявку. Слот недоступен другим заявкам, пока текущая ожидает/подтверждена.
- Занятия: подтвердить слот; после его начала назначенный инструктор может отметить занятие, навыки и рекомендации.
- Медиа: загрузка файлов до 25 МБ, выбор фото/видео, заголовок, язык. Для внешнего видео используйте `https://www.youtube-nocookie.com/embed/VIDEO_ID` или `https://player.vimeo.com/video/ID`. Для фонового локального видео через расширенные поля добавьте `{"placement":"hero"}`. Внешние фоновые iframe не запускаются автоматически.
- Отзывы: только с отмеченным разрешением на публикацию. Проверка происхождения и согласия — ответственность владельца, автоматической проверки подлинности нет.
- FAQ / Знания AI: вопрос, утверждённый ответ, категория, язык, источник, дата проверки, ответственный, статус. Изменения фиксируются в истории. Пока платная ветка отключена, консультант отвечает на нормализованные точные вопросы из этой базы и передаёт неизвестные школе.
- Переводы: ключ из `messages/ru.json`, новый текст, язык, статус published. Изменение видно после перезагрузки страницы. Переводы страницы и форм хранятся отдельно от переводов записей курсов/FAQ.
- Материалы: заголовок, описание, безопасный HTTPS URL. Сейчас это опубликованные общие материалы, не индивидуальные приватные файлы ученика.
- Вопросы экзамена: через форму или защищённый API `POST /api/admin/questions` с `{questions:[...]}`. Обязательны source, verifiedAt, verified=true, объяснение и правильный индекс; индексы в JSON от нуля. Переводы вопросов — отдельные записи. Не загружайте непроверенную базу. На этой стадии обучение и наполнение отложены.
- Настройки: поддерживаются только `booking_enabled`, `site_description`, `exam_minutes`, `exam_question_count`; значение задаётся в поле value. Публикация локальной записи не публикует сайт в интернете.
- Импорт обращений: JSON-массив строк / объектов с полем `text` или `message`, объект `{messages:[...]}`, обычные строки или простой CSV (текст последней колонки, без поддержки сложных quoted CSV). Для сложных CSV сначала экспортировать JSON. Маскирование не гарантирует удаления имён и всех идентификаторов — проверить вручную. Смысловая группировка и AI-черновики отложены.

Не помещайте ключи API в CMS, расширенные JSON-поля, переводы или материалы. Секреты — только серверные переменные окружения.
