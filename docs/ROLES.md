# Роли и права

Одно место правды в коде: `src/lib/roles.ts`. Сервер проверяет права сам, кнопки в интерфейсе только подсказка.

| Роль | Кабинет | Что может |
|---|---|---|
| admin (несколько человек) | `/ru/admin` | Всё: цены, роли, настройки, создание сотрудников, финансовые итоги и статистика |
| manager | `/ru/manager` | То же, что оператор (отдельная роль на будущее) |
| operator (секретари, у каждого свой вход) | `/ru/operator` | Заявки и занятия, перенос и закрытие, расписание, ученики, сброс пароля ученику, обращения, **оплаты и долги**, правка фото, видео, инструкторов, филиалов, программ, отзывов, FAQ |
| instructor | `/ru/instructor` | Свои занятия и свои ученики |
| lecturer | `/ru/lecturer` | Как инструктор, для теории |
| student | `/ru/account` | Свои записи |

## Деньги
- Таблицы `charges` (начисления) и `payments` (оплаты). Суммы хранятся в тетри (1/100 лари).
- Запись о заявке с ценой пакета создаёт начисление автоматически. Оператор может добавить начисление вручную.
- Оплат на одно начисление может быть сколько угодно (аванс по частям): сумма, способ (наличные, карта, перевод), комментарий.
- Оператор видит по каждому ученику: начислено, оплачено, процент, остаток. Общих итогов у него нет.
- Отмена записи: своя запись в течение 24 часов у оператора, любая у админа. Запись не удаляется, а помечается отменённой с причиной. Всё пишется в журнал `audit`.
- Отчёт (поступления по месяцам, по способам, всего долгов, статистика учеников по полу и возрасту): только admin.

## Сотрудники
Админ создаёт сотрудника в кабинете (Ученики, Добавить сотрудника): имя, телефон, роль. Система выдаёт временный пароль один раз, при первом входе его нужно сменить. Роль admin нельзя понизить через интерфейс.
