# Пакеты занятий

Пока пакетов нет, на главной, в «Программах» и «Стоимости» показываются анимированные
заглушки «Пакет готовится», а в форме записи ученик сам выбирает количество занятий (1–20).
Как только в админке опубликован хотя бы один пакет на языке страницы, заглушки исчезают.

## Как прислать пакеты

Достаточно обычного текста, по одному блоку на пакет:

```
Название: Уверенный водитель
Занятий: 10
Длительность занятия: 60 мин
Цена: 450 ₾            (можно «уточняется»)
Старая цена: 500 ₾     (необязательно, будет зачёркнута)
Коробка: механика / автомат / не важно
Что входит:
- Город и трасса
- Экзаменационный маршрут
Описание: Оптимальный курс перед экзаменом.
Популярный: да         (выделяется тёмной карточкой с бейджем)
```

Языки: текст нужен на каждом языке сайта (ka / hy / ru / en). Если прислать только на русском,
на остальных языках пакеты останутся заглушками, пока не будет перевода.

## Как внести вручную

`/ru/admin` → «Пакеты занятий» → «Добавить». Поля совпадают с шаблоном выше; статус
«Утверждено и опубликовано» делает пакет видимым. Пустая цена показывается как
«Стоимость уточняется» — она никогда не превращается в 0 ₾.

В заявке сохраняется снимок названия пакета (`Уверенный водитель · 10×60`), поэтому
последующая правка прайса не переписывает старые заказы.
